# 7) استكشاف الأعطال

## شاشة بيضاء بعد النشر

| السبب | الحل |
|---|---|
| مجلد Pages هو `/ (root)` | غيّره إلى `/docs` من Settings → Pages |
| Service Worker يخزّن `index.html` قديمًا | افتح `/reset.html` أو زر «مسح الذاكرة المؤقتة» في شاشة الخطأ — لا تدخل `index.html` أو باث مطلق في `PRECACHE` |
| مسارات مطلقة باسم المستودع (`/anti/assets/...`) | لا تحقن `VITE_BASE_PATH` بقيمة مطلقة؛ الحزمة مبنية بأصول نسبية `./` |
| استخدام BrowserRouter | استخدم `VITE_ROUTER_MODE=hash` |
| Jekyll يتجاهل الأصول | تأكد من وجود `docs/.nojekyll` |

## «إعدادات الاتصال مفقودة»

`docs/config.js` غير موجود أو حُمّل بعد وحدة التطبيق.
يجب أن يسبق وسم `<script src="./config.js">` وسم `<script type="module">` في `index.html`.

## «هذه العملية تتطلب مصادقة ثنائية (AAL2)»

فعّل TOTP من **حسابي والأمان**، ثم سجّل خروجًا ودخولًا وأكمل تحدي الرمز.

## «لا تملك الصلاحية اللازمة»

حسابك بلا دور مناسب. من حساب `system_admin`: **المستخدمون → الأدوار**.

## «حسابك بانتظار التفعيل» لا تزول

الحساب موجود في `auth.users` لكن بلا ملف في `public.users` أو بلا أدوار.
شغّل [`04-first-admin.md`](04-first-admin.md) أو اطلب من المدير تفعيلك.

## استدعاءات الدوال ترجع 404

دوال الحافة لم تُنشر بعد ← [`03-backend.md`](03-backend.md).

سلوك مقصود: يُمنع استلام أو صيانة أو فرمتة جهاز عليه بلاغ نشط،
ويُسجَّل حدث أمني حرج يظهر في صفحة **الأحداث الأمنية**.

## فشل `npm run verify`

| الرسالة | الحل |
|---|---|
| `فحص الأسرار فشل` | أزل المفتاح/السر المذكور من الملف |
| `schema.sql غير متزامن` | شغّل `npm run sql:bundle` |
| `اختلال أقواس` | راجع الملف؛ غالبًا `coalesce(jsonb_agg(...))` أُغلق قبل `from (...)` |
| `فحص PWA فشل` | أعد البناء؛ تأكد من ترتيب `config.js` في `index.html` |
