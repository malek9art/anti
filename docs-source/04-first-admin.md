# 4) إنشاء أول مدير

لا يوجد حساب مدير ثابت ولا بيانات تجريبية في المشروع. أول مدير يُنشأ عبر سكربت آمن.

## الخطوات

1. افتح موقع المنصة: `https://<owner>.github.io/<repo>/`
2. اختر تبويب **«حساب جديد»** وسجّل بريدك وكلمة مرور قوية (10 أحرف فأكثر).
3. أكّد البريد إن طلب Supabase ذلك.
4. سترى شاشة **«حسابك بانتظار التفعيل»** — هذا متوقع.
5. افتح **Supabase → SQL Editor**، والصق محتوى
   [`supabase/scripts/bootstrap_first_admin.sql`](../supabase/scripts/bootstrap_first_admin.sql).
6. **غيّر السطر التالي** إلى بريدك الفعلي:

   ```sql
   v_email text := 'CHANGE_ME@example.com';
   ```

7. اضغط **Run**. ستظهر رسالة `تم إنشاء المدير الأول: ...`
8. ارجع للموقع واضغط **«تحديث الحالة»** — ستدخل بدور `system_admin`.

## بعد ذلك مباشرة

1. اذهب إلى **حسابي والأمان** وفعّل **المصادقة الثنائية (TOTP)**.
   بدونها ستُرفض كل العمليات الحساسة خادميًا (AAL2 مطلوب).
2. من صفحة **المستخدمون** فعّل بقية الحسابات وأسند لها الأدوار المناسبة.

## ملاحظات أمنية

- السكربت لا يحتوي على UUID ثابت ولا بريد ثابت.
- إن لم يُعثر على المستخدم في `auth.users` سيتوقف السكربت برسالة واضحة.
- تشغيله مرة أخرى بنفس البريد آمن (idempotent).
